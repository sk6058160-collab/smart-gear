# Smart Gear 🚗⚙️

**NYC rideshare drivers ke liye simple hisaab app.** Earnings, expenses, trip profit calculator ($/mile, $/hour, deadhead, tolls), shift timer, goals, aur Ride Scanner (NYC hotspots + airport ride ke andaze). Sab data sirf aapke phone pe rehta hai. Offline chalta hai, koi account nahi chahiye.

> Ride Scanner ke scores sirf **andaza / estimate** hain. Ye real Uber/Lyft demand data nahi hai. Not affiliated with Uber, Lyft, Revel or NYC TLC.

## Open the app

## iPhone pe install (Home Screen app)
1. iPhone pe **Safari** me upar wala link kholo.
2. Neeche **Share** button (⬆️ box wala icon) dabao.
3. **Add to Home Screen** choose karo, phir **Add** dabao.
4. Home Screen pe **Smart Gear** icon se app kholo. Ek baar khulne ke baad offline bhi chalega.

## Android
- **APK download:** https://sk6058160-collab.github.io/smart-gear/smart-gear.apk
  (Debug-signed APK hai. Install ke time "unknown apps / sources se install" allow karna padega.)
- Ya Chrome me web link kholo → ⋮ menu → **Add to Home screen / Install app**.
